# Thai GL Stole My Sleep 

> 網址：https://zoeyy89.github.io/thai-gl-drama/  
> 泰國泰百劇介紹網站，收錄 2014–2025 年泰百劇集資料。

## 功能
- 劇集列表（按年份分組，支援年份＋標籤篩選）
- 劇集詳情（評分、標籤、CP、主題曲、預告片）
- CP 介紹（演員資訊、出演作品）
- 收藏功能（本地儲存）

## 工具和函式庫
- React 18 + Vite
- React Router v6
- JavaScript
- GitHub Pages
